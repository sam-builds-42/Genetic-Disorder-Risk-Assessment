
# Explainable Genetic Disorder Risk Assessment System

## About the Project
An educational machine learning project that uses a
Decision Tree classifier to predict a genetic disorder
category from user-entered features.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Features
- Interactive input form
- Predicted disorder category
- Model score comparison
- Decision Tree explanation
- Model evaluation information

## How to Run

1. Install Python.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Disclaimer
This project is for educational and demonstration
purposes only. It is not a medical diagnostic tool
and must not be used to make healthcare decisions.
